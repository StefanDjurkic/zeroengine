live 3D demo · JSPP code drives the cube below · running in your browser

This cube's rotation, colors, and click behavior are computed by the JSPP interpreter every frame. The source on the right is the actual code running — edit mentally, then hit "Open Playground" to really edit it.

JSPP is a TypeScript-flavored language that compiles to modern C++20. ZeroEngine is a Rust game engine that ships to WebAssembly. Together they let you write clean high-level code for real 3D.
