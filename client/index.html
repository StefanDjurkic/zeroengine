JSPP x ZeroEngine

live 3D demo - JSPP code drives this cube in real time

The cube's rotation, color, and click behavior are all computed by the JSPP interpreter running in your browser. JSPP is a TypeScript-flavored language that compiles to modern C++20.

Want to write your own JSPP? Open the playground - real editor, 2D and 3D modes, five working examples.
